1. OVERVIEW SISTEM
============================================================

Alur absensi try out:

  Casis join Discord → React role "Casis"
           ↓
  Buka web /absen → Login → Isi form
           ↓
  Bot Discord assign role "Tahap Akademik"
           ↓
  Casis bisa akses channel Try Out

Komponen:
  - Web App (Next.js) → Hosted di Netlify
  - Discord Bot (Node.js) → Hosted di Railway
  - Database (PostgreSQL) → Supabase

3. DISCORD DEVELOPER PORTAL SETUP
============================================================

LANGKAH 1: Buat Application
─────────────────────────────

1. Buka browser → https://discord.com/developers/applications

2. Klik tombol "New Application" ( pojok kanan atas)

3. Isi form:
   - Name: Bareskrim Rekrutmen Bot
   - Checkbox: "By checking this box, you are agreeing to our
     Developer Terms of Service"
   
4. Klik "Create"

LANGKAH 2: Copy Client ID
──────────────────────────

1. Di halaman Application → Tab "General Information"
2. Copy "CLIENT ID" (angka panjang)
3. Simpan dulu, nanti dipakai

LANGKAH 3: Buat Bot
───────────────────

1. Tab "Bot" (di sidebar kiri)
2. Klik "Reset Token"
3. Klik "Yes, do it!"
4. Copy TOKEN yang muncul (simpan, jangan share!)
5. Scroll ke bawah → "Privileged Gateway Intents":
   - ✅ MESSAGE CONTENT INTENT → ON
   - ✅ SERVER MEMBERS INTENT → ON
6. Klik "Save Changes"

LANGKAH 4: Generate Invite Link
───────────────────────────────

1. Tab "OAuth2" → "URL Generator"
2. SCOPES:
   - ✅ bot
   - ✅ applications.commands
3. BOT PERMISSIONS:
   - ✅ Manage Roles
   - ✅ Send Messages
   - ✅ Use Slash Commands
   - ✅ Read Message History
4. Copy "Generated URL" di bawah

LANGKAH 5: Invite Bot ke Server
───────────────────────────────

1. Buka Generated URL di browser baru
2. Pilih server: "Pusdik Reserse Bareskrim"
3. Klik "Authorize"
4. Bot akan muncul di daftar member (status offline dulu)

4. SETUP SERVER DISCORD
============================================================

LANGKAH 1: Buat Role "Tahap Akademik"
──────────────────────────────────────

1. Buka Discord → Server Settings → Roles
2. Klik "Create Role"
3. Isi:
   - Name: Tahap Akademik
   - Color: Gold (#D4AF37)
4. Permissions:
   - ✅ View Channels
   - ✅ Send Messages
   - ✅ Connect (voice)
   - ✅ Speak
5. Klik "Save"
6. Copy Role ID:
   - Aktifkan Developer Mode: Settings → Advanced → Developer Mode ON
   - Klik kanan role "Tahap Akademik" → Copy Role ID
   - Simpan ID ini

LANGKAH 2: Buat Channel Try Out
───────────────────────────────

Buat channel baru dengan permission gating:

1. Channel Text: #tahap-akademik
   - Klik "+" di Text Channels
   - Name: tahap-akademik
   - Permissions:
     - @everyone: ❌ View Channel
     - Tahap Akademik: ✅ View Channel
   
2. Channel Voice: Tahap Interview
   - Klik "+" di Voice Channels
   - Name: Tahap Interview
   - Permissions:
     - @everyone: ❌ View Channel
     - Tahap Akademik: ✅ View Channel

3. Channel Text: #tahap-fisik
   - Name: tahap-fisik
   - Permissions:
     - @everyone: ❌ View Channel
     - Tahap Akademik: ✅ View Channel

LANGKAH 3: Copy Server ID
─────────────────────────

1. Klik kanan server name → Copy Server ID
2. Simpan ID ini (GUILD_ID)

5. DEPLOY DISCORD BOT (RAILWAY)
============================================================

LANGKAH 1: Buat Akun Railway
─────────────────────────────

1. Buka https://railway.app
2. Klik "Login" → "Login with GitHub"
3. Authorize Railway

LANGKAH 2: Buat Project Baru
─────────────────────────────

1. Dashboard → Klik "New Project"
2. Pilih "Deploy from GitHub repo"
3. Pilih repository: muhadilaga/bareskrim-rekrutmen
4. Pilih folder: discord-bot
   (Railway akan detect package.json)
5. Klik "Deploy"

LANGKAH 3: Setup Environment Variables
──────────────────────────────────────

1. Klik project yang baru dibuat
2. Tab "Variables"
3. Tambah variabel berikut:

   DISCORD_TOKEN = [token bot dari Developer Portal]
   CLIENT_ID = [client ID dari Developer Portal]
   GUILD_ID = [server ID Discord]
   TAHAP_AKADEMIK_ROLE_ID = [role ID "Tahap Akademik"]
   PORT = 3001
   WEB_API_SECRET = BareskrimBotSecret2026

LANGKAH 4: Generate Domain
──────────────────────────

1. Tab "Settings"
2. Section "Networking" → "Generate Domain"
3. Copy domain yang diberikan (misal: bareskrim-bot-production.up.railway.app)
4. Simpan URL ini untuk web app

LANGKAH 5: Cek Bot Online
─────────────────────────

1. Tab "Deployments" → Klik deployment terbaru
2. Lihat logs → Harus muncul:
   "✅ Bot logged in as Bareskrim Rekrutmen Bot#xxxx"
   "🌐 API server running on port 3001"

3. Buka browser: https://[domain-railway]/api/health
   Response: {"ok":true,"bot":"connected","uptime":...}

6. SETUP ENVIRONMENT VARIABLES (WEB APP)
============================================================

LANGKAH 1: Netlify Dashboard
─────────────────────────────

1. Buka https://app.netlify.com
2. Pilih site: bareskrim-rekrutmen
3. Site settings → Environment variables

LANGKAH 2: Tambah Variabel Baru
───────────────────────────────

Klik "Add a variable" → Tambah:

Key: DISCORD_BOT_API_URL
Value: https://[domain-railway]   ← URL dari Railway

Key: DISCORD_BOT_SECRET
Value: BareskrimBotSecret2026

Key: TAHAP_AKADEMIK_ROLE_ID
Value: [role ID "Tahap Akademik"]

LANGKAH 3: Deploy Ulang
───────────────────────

1. Tab "Deploys" → Klik "Trigger deploy"
2. Pilih "Deploy site"
3. Tunggu sampai "Published"

7. PRISMA MIGRATION
============================================================

LANGKAH 1: Pull Environment Variables
──────────────────────────────────────

Buka terminal di PC:

cd bareskrim-rekrutmen

# Pastikan .env sudah ada
copy .env.example .env

# Isi DATABASE_URL di .env
# (dari Supabase: postgresql://postgres.xxx:password@db.xxx.supabase.co:5432/postgres?sslmode=require)

LANGKAH 2: Run Migration
─────────────────────────

npx prisma migrate dev --name add-attendance

Jika sudah production:
npx prisma migrate deploy

LANGKAH 3: Generate Prisma Client
──────────────────────────────────

npx prisma generate

============================================================
9. TROUBLESHOOTING
============================================================

MASALAH: Bot tidak online di Discord
─────────────────────────────────────
- Cek token Discord benar di Railway
- Cek logs Railway untuk error message
- Pastikan bot sudah di-invite ke server

MASALAH: Role tidak terassign
──────────────────────────────
- Cek GUILD_ID benar
- Cek TAHAP_AKADEMIK_ROLE_ID benar
- Pastikan bot punya permission "Manage Roles"
- Pastikan role bot lebih tinggi dari "Tahap Akademik"

MASALAH: API error 401 Unauthorized
────────────────────────────────────
- Cek WEB_API_SECRET sama di web app dan bot
- Cek DISCORD_BOT_API_URL benar

MASALAH: Prisma migration error
───────────────────────────────
- Cek DATABASE_URL benar
- Cek koneksi database (Supabase harus aktif)
- Jalankan: npx prisma db push

MASALAH: Halaman /absen 404
───────────────────────────
- Cek file src/app/absen/page.tsx ada
- Deploy ulang ke Netlify

MASALAH: Form absensi tidak muncul
──────────────────────────────────
- Cek browser console untuk error
- Pastikan user sudah login
- Cek API /api/attendance/check
