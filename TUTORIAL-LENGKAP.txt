1. OVERVIEW
============================================================

Sistem ini adalah platform rekrutmen dan ujian online untuk
Bareskrim Polri Roleplay di Roblox.

Fitur Utama:
- Login otomatis pakai username Roblox
- Verifikasi otomatis (grup, pangkat, blacklist)
- Ujian Pilihan Ganda & Essay (auto-grading)
- Absensi Discord otomatis + assign role
- Admin panel lengkap (kelola periode, soal, casis)

URL Penting:
- Homepage    : https://NAMA-SITE.netlify.app
- Login       : https://NAMA-SITE.netlify.app/login
- Ujian       : https://NAMA-SITE.netlify.app/ujian
- Admin       : https://NAMA-SITE.netlify.app/admin
- Health Check: https://NAMA-SITE.netlify.app/api/health

2. GUIDE UNTUK INSTRUKTUR/ADMIN
============================================================

2.1 Login Admin
-------------
1. Buka https://NAMA-SITE.netlify.app/admin
2. Masukkan ADMIN_KEY (password admin)
3. Klik "Masuk"

2.2 Inisialisasi Database (Pertama Kali)
-----------------------------------------
1. Login ke admin panel
2. Jika muncul kartu "Database Belum Siap"
3. Klik tombol "Initialize Database"
4. Tunggu sampai semua tabel berhasil dibuat

2.3 Kelola Periode Rekrutmen
-----------------------------
Tab "Periode" → Kelola masa aktif rekrutmen

Buka Periode Baru:
1. Isi nama periode (contoh: "Gelombang 1 - 2026")
2. Isi jumlah soal PG dan Essay (opsional, default 15/5)
3. Isi KKM (opsional, default 70)
4. Klik "Buka Periode Baru"

Atur Periode:
- "Buka Ujian" → mengaktifkan sesi ujian untuk casis
- "Tutup Ujian" → menonaktifkan sesi ujian
- "Tutup Periode" → menutup periode secara permanen
- "Reset" → menghapus semua data periode (HATI-HATI!)

2.4 Kelola Bank Soal
---------------------
Tab "Bank Soal" → Tambah/hapus soal ujian

Tambah Soal Pilihan Ganda:
1. Pilih tipe "Pilihan Ganda"
2. Isi pertanyaan
3. Isi minimal 2 opsi jawaban (A, B, C, D, E)
4. Pilih indeks jawaban benar (0=A, 1=B, 2=C, dst)
5. Isi poin (default 4)
6. Klik "Tambah Soal"

Tambah Soal Essay:
1. Pilih tipe "Essay"
2. Isi pertanyaan
3. Isi kata kunci pemisah koma (contoh: "python,list,for")
4. Isi poin (default 8)
5. Klik "Tambah Soal"

Hapus Soal:
- Klik "Hapus" pada soal yang dipilih
- Atau "Hapus Semua PG" / "Hapus Semua Essay"

2.5 Kelola Casis
-----------------
Tab "Casis" → Lihat dan kelola semua peserta

Status Casis:
- Belum Absen: terdaftar tapi belum absen
- Sudah Absen: sudah absen, belum mulai ujian
- Sedang Mengerjakan: sedang mengerjakan ujian
- Selesai: sudah menyelesaikan ujian

Aksi:
- "Refresh" → muat ulang data
- "Hapus" → hapus satu casis
- "Hapus Semua" → hapus semua casis (konfirmasi 2x)
- "Grup" → lihat grup Roblox & server Discord

2.6 Rekap Hasil
----------------
Tab "Rekap" → Lihat ringkasan hasil ujian

- Total peserta, lulus, tidak lulus
- Persentase kelulusan
- Rata-rata skor

Export CSV:
- Klik "Export CSV"
- File tersimpan dengan format nama periode
- Kolom: No, Nama, Username, RobloxID, Discord, Pangkat,
         PG, Essay, Total, Persentase, Status, Waktu

2.7 Discord Messages
---------------------
Tab "Discord" → Kelola pesan notifikasi di Discord

- Lihat semua pesan bot di channel
- Hapus pesan per individu
- "Hapus Semua" → hapus semua pesan bot

2.8 Log Aktivitas
------------------
Tab "Log" → Lihat semua aktivitas admin

- Siapa yang melakukan aksi
- Aksi apa yang dilakukan
- Kapan dilakukan

3. GUIDE UNTUK CASIS (PESERTA)
============================================================

3.1 Login
----------
1. Buka https://NAMA-SITE.netlify.app
2. Klik "Login" atau masukkan username Roblox
3. Sistem akan memverifikasi akun Roblox Anda
4. Pastikan akun sudah join grup yang diperlukan

Persyaratan Login:
- Akun Roblox aktif
- Sudah join grup [RI] Republic Indonesia
- Sudah join grup Kepolisian dengan pangkat minimal
- Tidak masuk blacklist

3.2 Absen
-----------
1. Setelah login, Anda akan diarahkan ke halaman absen
2. Isi username Discord Anda
3. Klik "Absen"
4. Anda akan otomatis mendapat role di Discord

Catatan:
- Absen hanya bisa dilakukan 1x per periode
- Username Discord harus valid dan ada di server

3.3 Mengerjakan Ujian
-----------------------
1. Setelah absen, tunggu instruktur membuka sesi ujian
2. Ketika sudah dibuka, klik "Mulai Ujian"
3. Anda akan melihat soal Pilihan Ganda dan Essay

Aturan Ujian:
- Waktu ujian: 45 menit (default)
- Soal Pilihan Ganda: pilih satu jawaban
- Soal Essay: ketik jawaban teks bebas
- Jawaban tersimpan otomatis di browser (localStorage)

Fitur Resume:
- Jika browser crash, buka kembali /ujian
- Jawaban akan dipulihkan dari localStorage
- Tidak perlu absen ulang

Submit Ujian:
- Setelah semua soal dijawab, klik "Submit Ujian"
- Konfirmasi submit
- Hasil akan langsung tampil

3.4 Melihat Hasil
------------------
- Setelah submit, skor langsung tampilkan
- Skor Pilihan Ganda: otomatis dihitung
- Skor Essay: dihitung berdasarkan kata kunci
- Status: Lulus/Tidak Lulus berdasarkan KKM

4. TROUBLESHOOTING
============================================================

Masalah: Login gagal / "Username tidak ditemukan"
Solusi: Pastikan username Roblox sudah benar dan akun aktif

Masalah: "Grup tidak memenuhi syarat"
Solusi: Pastikan sudah join grup yang diperlukan di Roblox

Masalah: Halaman admin minta password
Solusi: Masukkan ADMIN_KEY yang benar

Masalah: Ujian tidak bisa dimulai
Solusi: Tunggu instruktur membuka sesi ujian terlebih dahulu

Masalah: Browser crash saat ujian
Solusi: Buka kembali /ujian, jawaban tersimpan otomatis

Masalah: Build/Deploy gagal di Netlify
Solusi: Cek environment variables sudah lengkap

Masalah: Discord role tidak ter-assign
Solusi: Cek DISCORD_BOT_TOKEN dan TAHAP_AKADEMIK_ROLE_ID

Masalah: Error "Database belum diinisialisasi"
Solusi: Login admin → klik "Initialize Database"

5. DAFTAR ENVIRONMENT VARIABLES
============================================================

DATABASE (Wajib):
  DATABASE_URL          = URL koneksi PostgreSQL
  JWT_SECRET            = Secret key untuk JWT (minimal 32 karakter)

ADMIN (Wajib):
  ADMIN_KEY             = Password admin panel

DISCORD (Wajib untuk fitur Discord):
  DISCORD_WEBHOOK_URL        = URL webhook notifikasi umum
  DISCORD_PUSDIK_WEBHOOK_URL = URL webhook channel pusdik
  DISCORD_BOT_NAME           = Nama bot Discord
  DISCORD_GUILD_ID           = ID server Discord
  DISCORD_CHANNEL_ID         = ID channel utama
  DISCORD_BOT_TOKEN          = Token bot Discord
  TAHAP_AKADEMIK_ROLE_ID     = ID role untuk casis
  TAHAP_INTERVIEW_ROLE_ID    = ID role untuk yang lulus ujian (auto-assign)

NOTE: Jika casis LULUS → otomatis dapat role "Tahap Interview"
      Jika casis TIDAK LULUS → role "Tahap Akademik" dilepas + terima DM notifikasi
  DISCORD_PUTUSAN_CHANNEL_ID = ID channel putusan
  DISCORD_BLACKLIST_POLRI_CHANNEL_ID     = ID channel blacklist Polri
  DISCORD_BLACKLIST_PENDIDIKAN_CHANNEL_ID = ID channel blacklist Pendidikan

ROBLOX (Wajib untuk verifikasi):
  REQUIRED_GROUP_ID    = ID grup [RI] Republic Indonesia
  REQUIRED_GROUP_NAME  = Nama grup required
  POLICE_GROUP_ID      = ID grup Kepolisian
  POLICE_GROUP_NAME    = Nama grup Kepolisian
  MIN_POLICE_RANK      = Pangkat minimal (angka)
  MIN_POLICE_RANK_NAME = Nama pangkat minimal
  BANNED_GROUP_IDS     = ID grup yang dibanned (pisah koma)
  BANNED_GROUP_NAMES   = Nama grup yang dibanned

UJIAN (Opsional):
  KKM                    = Nilai kelulusan (default: 70)
  MCQ_COUNT              = Jumlah soal PG (default: 15)
  ESSAY_COUNT            = Jumlah soal Essay (default: 5)
  MCQ_POINTS             = Poin per soal PG (default: 4)
  ESSAY_POINTS           = Poin per soal Essay (default: 8)
  EXAM_DURATION_MINUTES  = Durasi ujian dalam menit (default: 45)
